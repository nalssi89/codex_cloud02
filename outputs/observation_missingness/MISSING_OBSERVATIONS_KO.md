# 신규 관측 기온·강수 누락 전체 내역

관측 스냅샷: **1991-01-01–2026-10-05**, 고정 ASOS 62지점. 실제 결측 발생일은 아래 표와 CSV에 모두 기재했습니다. 이전 자료는 권역 평균만 있어 이전 누락의 개별 지점·값을 동일하게 역추적할 수 없습니다. 이 파일은 신규 원자료의 확인 가능한 내역입니다.

## 값의 해석

- 기온 원시값 `-99`는 **결측 코드**이며 -99°C라는 측정값이 아닙니다. 실제 기온은 알 수 없습니다.
- `STATION_DATE_ROW_MISSING`은 해당 지점·날짜의 **API 응답 행 자체가 없음**을 뜻합니다. 기온과 강수 모두 값이 없고, 강수 0mm로 간주하지 않습니다. 지점 폐쇄나 실제 미관측을 단정하는 표시는 아닙니다.
- 실제값은 보간·추정하지 않았습니다. CSV의 `OBSERVED_VALUE`는 전부 빈칸이며, `RAW_VALUE`는 반환된 결측 코드가 있을 때만 -99입니다. CSV는 Excel 한글 호환을 위해 UTF-8 BOM으로 저장했습니다.
- 강수는 반환된 행의 별도 무효값 결측은 0건입니다. `RN_DAY=-9`는 기존 kmahub 정책에 따라 0으로 해석하므로 아래 결측 목록에 포함하지 않았습니다. 이는 별도 기기 QC 인증이 아닙니다.
