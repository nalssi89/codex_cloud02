## 먼저 볼 내용

보고서의 **방법 비교표**와 **권장하는 첫 실험**을 먼저 보시면 됩니다.
새 추론 비교는 평균 기반 BJP, 작은 대조군은 기후 CDF 수축·제한 MOS,
강수 확장은 실제 0 빈도를 확인한 Gamma/CSG입니다.

이 순서는 한국 자료에서 관측한 성능 순위가 아닙니다. 새 보정 모형의 실제 적합은 수행하지 않았고 기존 생산 코드·관측·결과는 변경하지 않았습니다.
합성 계산과 보고서 화면 검증을 후보 모형의 효능 검증으로 해석하지 마십시오.
