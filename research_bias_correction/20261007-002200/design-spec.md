# Design specification
Language: Korean
Template: clean analyst report
Palette: --accent #176b87; --text #172b35; --muted #526773; --background #f5f8fa; --surface #ffffff; --rule #dbe4e9
Typography: Noto Sans KR real local webfont when available; Malgun Gothic sans-serif fallback.
Layout: max-width 1120px; mobile breakpoint 700px; word-break: keep-all; overflow-wrap: anywhere.
Figures: fixed-size container, contain-fit, caption, original aspect preserved.
Lineage: section
Citations: [Source N] links to numbered sources; local project paths with line anchors.
Structure: executive summary; project constraints; method comparison; method details; priorities; validation; gaps; sources; methodology.
No invented performance chart. Decision diagram is qualitative, not a measured skill ranking.
