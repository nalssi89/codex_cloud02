1. 현재 자료에서 중요한 조건

현재 보정 타깃은 권역 평균이다. 이 연구에 사용할 예보·관측 보정 인터페이스는 권역 집계이며, 개별 지점·격자에 대응하는 예보와 joint 자료가 확보됐다고 가정하지 않는다. 1mon은 주간 구간, 3mon은 개별 달력 월이며 3개월 합계가 아니다. 기온은 구간 평균 °C, 강수는 구간 누적 mm다. 조사 중 다른 작업이 관측을 재수집해 최신 기준이 갱신됐다. 현재 보고서는 KMA API Hub의 지점·날짜 원자료에서 유효한 실제 기여 지점의 동일 가중 평균, 변수별 최소 50지점, 보간·62/n 확대 없음을 사용한다. 3. Joint Gaussian과 BJP

무엇이 ‘joint’인가

기본형에서 joint는 한 변수의 예측 앙상블 평균 X와 대응 관측 Y의 결합분포를 뜻한다. 기온과 강수를 함께 예측하는 것은 별도 다변량 확장이다. 변환한 X·Y를 결합 정규로 두면, 고정된 모수에서 다음 조건부 식이 나온다. Source 6

E(Y|X=x) = μy + Σyx Σxx⁻¹ (x−μx)
Var(Y|X) = Σyy − Σyx Σxx⁻¹ Σxy

이 식은 Gaussian MOS 회귀와 밀접하지만, 현재 CRPS 최소화·계수 제약·앙상블 spread에 따른 분산을 가진 EMOS와 동일한 적합 모형이라는 뜻은 아니다. 기본 결합 정규의 조건부 잔차 분산은 고정이고, mean-only BJP는 원시 앙상블 spread 정보를 쓰지 않는다. Source 6 Source 76 [Project P3]

BJP(Bayesian Joint Probability)는 결합분포 모수의 사후분포에 대해 조건부 예측분포를 평균한다. 각 모수에서 정규라도 최종 사후 예측은 일반적으로 단일 정규가 아니며 자동으로 t분포가 되지도 않는다. 일부 원전은 변환 모수를 MAP로 정한 뒤 고정하므로 ‘모든 불확실성을 전파한다’고 설명하면 부정확하다. Source 5 Source 6 Source 14

장점과 단점

  • 장점: 예보-관측의 조건부 관계를 학습한다. 짧은 자료에서 모수 불확실성을 명시하고, 예측 관계가 약하면 관측 기후분포에 가까운 예측을 낼 수 있다. 원시 멤버 ID 없이 연도별 평균-관측 쌍으로 시작할 수 있다.
  • 단점: 변환·prior·MCMC 진단이 필요하고 역변환 꼬리가 민감하다. spread를 추가하면 모수가 늘고, Bayesian이라는 이름 자체가 적절한 calibration을 보장하지 않는다.
  • 현재 적용: 우선 기온의 단변량 평균 기반 BJP를 현행 EMOS와 비교한다. 강수는 정확한 0을 잠재 변환 공간의 검열 사건으로 처리하고, 원래 단위 예측 CDF·평균·분위수를 검산해야 한다. 예측 평균을 단순히 잠재 평균의 역변환으로 계산하지 않는다. Source 5 Source 6 Source 8

기온-강수 다변량 BJP는 후순위다. Schepen 등은 호주 System4 계절 강수·최저·최고기온 실험에서 다변량 적합의 in-sample 이점이 교차검증에서 사라지는 과적합을 관찰했다. 원전은 36개 가용 연도, LOYO 적합별 35개 쌍을 사용했다. 이것은 모든 다변량 모형이 실패한다는 정리가 아니라 현재 짧은 표본에서 공분산 복잡도를 조심하라는 직접 관련 반례다. 동일 원전의 여러 게시 경로는 독립 복제 실험이 아니다. Source 1 Source 5

4. 강수의 분포·발생 모형

Gamma·CSG 확장

현재 강수 EMOS도 Y=max(0,Z)인 검열 정규이므로 이미 0의 점질량이 있다. CSG(censored shifted gamma)의 새로운 비교 요소는 양의 강수량의 왜도와 평균·분산·shift 연결이다. 일반적인 예는 다음과 같다. Source 4 Source 27 [Project P3]

G ~ Gamma(k, θ), δ ≥ 0
Y = max(0, G−δ)
P(Y=0) = F_G(δ)
F_Y(y) = F_G(y+δ), y ≥ 0

장점: 비음수·0 질량·양의 왜도를 한 분포로 구성하고 CRPS 기반 적합 경로가 있다. 단점: 발생 확률과 양의 꼬리가 결합되어 독립 조절이 어렵고, shift와 scale을 유연하게 잡으면 연간 소표본에서 불안정하다. 특정 축약 링크나 고정 shift는 후보 설계이지 모든 CSG 구현의 동일한 정형은 아니다. Source 4 Source 27 Source 33

Positive Gamma는 더 간결하지만 정확한 0 질량이 없다. 훈련 집계에서 0이 거의 없을 때 비교할 수 있으나, 짧은 표본에서 0을 못 봤다는 사실을 모집단 0 확률이 없다는 증명으로 쓰지 않는다. NOAA의 실험 서비스는 7/14일 누적 강수에 CSGD를 사용하므로 주간 누적이라는 시간척도 선례는 있다. 다만 미국 격자·공간/날짜 풀링 자료이지 한국 권역 월·주간의 효능 검증은 아니다. Source 2 Source 27 Source 31

Power-censor·hurdle

제곱근·세제곱근 등의 고정 power-censor는 기존 정규/검열 구조를 재사용하는 작은 비교군이다. 변환 공간에서 맞춘 CRPS와 원래 mm 공간 CRPS는 일반적으로 다르므로 최종 비교는 원래 단위 CDF로 수행한다. 문헌의 censored logistic 예제를 Gaussian의 실제 검증 결과로 잘못 인용하지 않는다. Source 28 Source 30

Hurdle은 발생 확률과 Y>0일 때의 Gamma/lognormal 양을 따로 적합한다. CSG나 BMA의 동의어가 아니다. 별도 발생 효과를 설명하는 장점이 있으나 dry/wet으로 표본이 나뉘며, 전부 wet인 훈련자료에서는 무벌점 logistic 절편이 발산하는 등 식별성 문제가 생긴다. 권역의 주간·월간 합에서는 실제 true-zero/near-zero/positive 빈도를 먼저 확인해야 한다. 일강수 0.1 mm 기준을 그대로 이식하지 않는다. Source 29 Source 30 [Project P1]

GEV·Tweedie와 꼬리

검열 GEV는 꼬리에 유연하지만 shape·유한 상한·수치 안정성이 소표본에서 부담이다. 누적 강수에 GEV를 쓰는 것은 조건부 분포 선택이지, 해당 누적량에 극값 정리를 바로 적용했다는 뜻은 아니다. shape를 고정·수축하는 비교부터 고려한다. Source 28

Tweedie (1 < p < 2)는 compound Poisson-Gamma 형태로 0과 양의 왜도를 함께 구성한다. 양수 조건부가 단일 Gamma인 것은 아니다. 월간 유역 평균 강수의 기후분포 적합 선례가 있지만, 그것은 예보 입력에 연결된 calibration 성능 근거와 다르다. p·분산 링크 식별과 수치 CDF 비용 때문에 현재는 탐색 후보로 두는 편이 합리적이다. Source 31 Source 32

기존 자료의 극단 강수에 관심이 있어도 자유 shape 모형을 먼저 선택하지 않는다. 훈련에 관측된 극단 수, 특정 임계값의 held-out Brier, 상위 분위수 calibration과 구간 폭을 함께 확인해야 한다. 이 보고서는 새로운 극단값 정확도를 측정하지 않았다. Source 27 Source 28 Source 64

5. 작은 모형·수축·혼합

제한 MOS와 기후 수축

제한 anomaly MOS는 train-only 기후평균에 대해 μ=μobs+β(f̄−μfcst)와 잔차 분산을 정의한다. 현재 EMOS의 slope/spread 항을 제한하는 중첩 대조군이며, 단일 점예측만으로 전체 분포의 CRPS와 비교해서는 안 된다. 일정 잔차 분산과 완전한 예측 CDF를 함께 발행한다. Source 40 Source 43 Source 44

기후 수축은 noisy한 신호를 기후 기준 쪽으로 당긴다. 가장 작은 실험은 기존 보정 CDF와 train-only 관측 기후 CDF를 섞는 것이다. Source 41 Source 42 Source 65

F(y) = λ F_cal(y) + (1−λ) F_clim(y), 0 ≤ λ ≤ 1

장점: 원 멤버 ID 없이 기온·강수에 적용하고 한 개의 제한된 가중치로 시작할 수 있다. 강수의 0 질량도 각 성분에 맞게 유지된다. 단점: 좋은 신호를 지울 수 있으며 λ 선택 자체가 과적합될 수 있다. 평균만 섞고 성분 간 차이가 만드는 분산을 누락하면 잘못된 혼합분포가 된다. Bayesian 회귀 수축을 택하면 실제 사후 예측분포를 평가해야 하며, 고정 Gaussian EMOS에 ‘모수 불확실성이 이미 전부 포함됐다’고 쓰면 안 된다. Source 41 Source 42 Source 65 합성 검증

BMA·커널 dressing

BMA는 성분 예측밀도를 가중 혼합한다. 기온은 Normal 성분, 강수는 0·양의 왜도 성분이 가능하다. 장점: 성분별 정보를 반영하고 멀티모달 예측을 만들 수 있다. 단점: 작은 관측 표본에서 가중치·성분 모수가 불안정하고 멤버 구성이 바뀌면 대응이 어려워진다. Source 29 Source 60 Source 61

현재는 array index에 멤버 고유의 skill 가중치를 붙이는 방법을 권하지 않는다. 과학적으로 확인된 생성 그룹이 있다면 그룹 안의 모수·가중치를 묶는 축약 BMA를 검토할 수 있다. 이것은 제안한 소표본 설계의 자료 gate이지 ‘BMA는 일반적으로 독립 멤버만 가능하다’는 정리는 아니다. 교환가능성과 독립성도 다르다. Source 61 [Project P3]

기온의 동등 가중 Gaussian kernel dressing은 공통 bias/slope/bandwidth로 각 유효 멤버 주변의 분포를 섞는 ID 불필요 대조군이다. raw 멀티모달 모양과 spread를 살릴 수 있지만 잘못된 raw 꼬리를 계속 물려받을 수 있다. 강수에 음수 support를 가진 일반 Gaussian kernel을 그대로 쓰지 않는다. BMA·dressing이 현행 EMOS보다 낫다는 결론은 이번 조사에 없다. Source 62 Source 63 Source 64

6. 풀링·추세·멤버 수

계수 부분 풀링

현재 자료에서 적용 가능한 풀링은 같은 변수·상품의 비교 가능한 달력 조건·lead에 걸친 계수 공유다. 인접 달력 조건의 cyclic smoothing이나 intercept/slope/log-scale의 규제를 검토할 수 있다. 개별 지역 자료가 없으므로 지역·관측소 hierarchy를 가진 것처럼 설계하지 않는다. Source 18 Source 40 [Project P1]

추세 보정

장점: 모형과 관측의 시간 의존적 차이를 다룬다. 단점: 짧은 기록의 slope·prior·외삽이 불안정하다. 추세 논문의 LOYO는 미래자료를 포함할 수 있으므로 운영 개선의 증명이 아니다. 강수에서 detrending하면 잠재 0 검열 경계도 시간에 따라 바뀌며 단순 고정 임계값을 재사용할 수 없다. 호주 공간 pool에서 정한 prior scale을 한국 권역에 그대로 옮기지 않는다. Source 3 Source 8 Source 10 Source 12

Finite-member signal-noise

Bayesian signal-noise는 역사 앙상블 평균의 표본 잡음과 발행 평균의 잡음이 멤버 수에 따라 달라짐을 모형화하는 후보다. GloSea5 NAO의 원전은 직접 관련된 계절 예측 사례지만 현재 기온·강수 검증 결과는 아니다. Source 14

7. 비선형·범주 예측

Ordinal·ELR

최종 상품이 BN/NN/AN 확률이면 ordered logistic 또는 ELR이 작은 비교 후보다. 공통 순서 절단점 모형은 일관된 범주 확률을 만들 수 있으며 ELR은 물리적 임계값을 입력하는 관련 접근이다. 둘은 동일 모형이 아니다. 독립 이진 회귀는 교차할 수 있고 빈 범주는 분리·불확실성을 만든다. 범주 확률 모형은 보정된 강수량·기온값이나 연속 CDF의 자동 대체물이 아니다. 실제 주간/격주 SubX·IRI 적용 선례는 있지만 현재 한국 자료의 성능 근거는 아니다. Source 21 Source 55 Source 56 Source 57

분포회귀 boosting·QRF·IDR

분포회귀 boosting/GAMLSS: 위치·scale의 작은 비선형·달력·lead 효과를 규제와 함께 학습한다. EMOS보다 링크가 유연해지는 장점이 있지만 선택한 분포의 support·꼬리 가정은 남는다. 큰 predictor 목록보다 작은 평균/spread/계절/lead 목록과 강한 규제부터 검토한다. componentwise boosting과 NGBoost는 다른 알고리즘이며 Normal 기본값이 강수의 0·음수 support 문제를 해결하지 않는다. Source 48 Source 49 Source 58

QRF: 관측의 조건부 가중 경험분포로 비선형·0값을 처리하고 다양한 분위수를 출력한다. 분포족 선택이 덜 필요하지만 기본형의 꼬리는 훈련 관측 범위를 벗어나지 못한다. 많은 나무가 새 관측 연도를 만들지 않으며 잎별 서로 다른 연도의 지원을 확인해야 한다. 안전한 조건 풀링이 가능하면 비교할 수 있으므로 ‘30개 쌍이면 모든 ML이 불가능하다’고 단정하지 않는다. 다만 관측 범위 밖 극단 extrapolation이 목적이면 별도 꼬리 확장이 필요하다. Source 45 Source 46 Source 47 Source 59

IDR: 지정한 확률순서 아래에서 일관된 조건부 CDF를 학습한다. 해석 가능한 비모수 대조군이지만 평균·spread 둘 다 늘면 강수가 확률적으로 커진다는 등 순서 가정을 검토해야 한다. 무튜닝이 표본 충분성을 뜻하지 않고, 원전의 일강수 적용에서는 EMOS/BMA보다 많은 훈련자료를 요구한다고 설명한다. 경험적 꼬리 한계도 있다. Source 50

직접 월간 QRF 문헌은 존재하지만 탄자니아의 공간 cluster·격자·lagged predictor 기반 예측이며 현재 한 권역의 앙상블 보정과 다르다. 원전의 train/test 구분 없는 normalization 정책도 복제하지 않는다. 월간 타깃이 같다는 것만으로 데이터 규모·누출 없는 검증이 같아지지 않는다. Source 25

DRN·BQN

DRN은 신경망으로 선택한 예측분포의 모수를 연결한다. Gaussian DRN은 비선형 mean/scale일 뿐 Bayesian 사후분포를 자동 적분하는 것은 아니다. BQN은 분위수 함수를 직접 구성해 유연하지만, 원래 Bremnes 구현은 단조성을 강제하지 않았으므로 교차가 드물었다는 결과를 무교차 보장으로 설명하면 안 된다. 다항 분위수의 유계 꼬리·강수 0 원자 처리는 별도 설계가 필요하다. Source 51 Source 52 Source 53

신경망의 계절·준계절 선례도 있다. 그러나 Alpine SEAS5 논문은 1개월 lead의 일별 격자 타깃이지 월간 권역 평균·합이 아니다. 전 지구 격주 신경망과 NOAA 주간 강수도 공간 풀링 자료를 사용한다. 현재 단일 권역의 고정 조건별 연간 표본에 그 학습 설정을 그대로 옮길 근거는 없다. 작은 pooled 모델은 조건부 실험, 큰 NN은 탐색 단계로 구분한다. Source 2 Source 24 Source 54

8. 공동사건·예측 경로

Schaake·ECC·잔차 copula

기온과 강수의 고온-건조 공동확률, 여러 주·월의 경로가 필요하면 주변분포 보정 이후 결합 층을 추가한다. 이것이 현재 단변량 CRPS를 더 좋게 만드는 방법이라는 설명은 잘못이다. Source 5 Source 66 Source 68

  • Schaake shuffle: 같은 역사 연도·정합된 달력 창의 관측 벡터 순위를 템플릿으로 재정렬한다. 원 멤버 ID는 불필요하지만 연도·유효 창이 일치한 관측 벡터는 필요하다. 구현이 단순하고 계절 비교 선례가 있으나 기후적 의존성을 쓰므로 흐름 의존적 변화나 짧은 템플릿의 잡음에 취약하다.
  • ECC: 발행 raw 멤버의 변수·lead 간 순위를 사용한다. 해당 발행의 물리적으로 일치한 원 멤버가 필요하고 array position은 그 증거가 아니다. raw 의존성이 좋으면 저비용이나 잘못된 의존성도 보존한다.
  • 잔차 Gaussian copula: 과거의 조건부 보정 CDF/PIT에 대한 잠재 잔차 의존성을 적합한다. 무조건부 관측 상관을 넣는 것과 다르다. raw ID 없이 가능하지만 강수 0 원자는 잠재 검열 구간 또는 정당화한 randomized PIT가 필요하고, 상관 수축·꼬리·공분산 안정성을 점검해야 한다. plug-in copula는 Bayesian joint posterior와 다르다. Source 5 Source 26 Source 66 Source 68 Source 71

같은 주변 값 multiset을 순열로 바꾸는 단계만 평균·분위수·삼분위 확률·empirical CRPS를 보존한다. 분석적 EMOS에서 유한 분위수·시나리오를 생성하는 단계는 그 분포의 근사이므로 exact analytic CRPS와 같다는 뜻이 아니다. 현재 QDM의 순위 역전 때문에 과거 index 그대로의 출력이 ECC라고 주장할 수도 없다. Source 5 [Project P2] 합성 검증

10. 공정한 검증 설계

  1. 예측 객체를 정의한다. 실제 발행 앙상블은 empirical CRPS, 연속·혼합 predictive CDF는 해당 분포 CRPS로 평가한다. 시나리오 근사와 analytic CDF를 구분하고 baseline을 조용히 이산화하지 않는다. Source 11 [Project P3]
  2. 연간 쌍을 훈련 단위로 둔다. 평균 기반 MOS/BJP는 연도당 한 쌍이다. 멤버별 loss로 확장하면 연도 내 멤버 가중치의 합이 해당 연도의 총 가중치가 되도록 한다. 경험분포의 equal-year weighting을 모든 모형의 보편 likelihood 공식으로 이식하지 않는다. Source 6 Source 14 [Project P3]
  3. 과거만 사용하는 outer 검증을 유지한다. 타깃 연도 제외·과거 끝일 cutoff를 모든 학습 단계에 적용한다. LOYO나 이웃 연도 제외 CV는 미래 추세 정보를 쓸 수 있어 운영 검증과 별도로 표시한다. Source 3 Source 8 Source 10 Source 12
  4. 동일 사례·QC·기후 경계를 비교한다. 새 방법의 적합 실패·대상 유지율을 별도 보고하고 성공 사례만 남겨 순위를 만들지 않는다. 강수 0 동률·삼분위 경계의 규칙을 명시한다. Source 16 [Project P1]
  5. 중복 유효 창의 의존성을 다룬다. 반복 발행은 실제 의사결정 사례이지만 독립 관측 반복이 아니다. all-issuance 결과와 equal-valid-window 가중 민감도를 함께 보고, paired 연도/의존성 블록과 연도별 영향을 확인한다. 약 다섯 발행 연도만으로 강한 유의성이나 견고한 CI를 주장하지 않는다. Source 16 Source 17 [Project P1]
  6. 점수·신뢰성을 함께 본다. 연속 CRPS·bias·RMSE, 삼분위 RPS/Brier·reliability, PIT(0 질량이면 해당 규칙), interval coverage/width, 사전 정의한 강수 상위 임계값을 사용한다. 공동 목적에는 단위 scaling을 훈련에서 정한 energy/variogram·joint-event Brier를 추가한다. Source 5 Source 27 Source 56 Source 71
  7. 자료 체계의 민감도를 분리한다. 동일 최근 타깃에서 공통 역사기간과 확장기간 적합을 비교한다. APCC 공식 설명에는 KMA 구성의 해양 초기화 자료 경계가 기록되어 있지만, 현재 공급 행에 대한 정확한 매핑과 편의 변화의 원인은 미확인이다. 기간 확대의 효과를 특정 초기장 변화에 인과 귀속하지 않는다. Source 13 Source 19 Source 20

fair CRPS를 공식 점수의 자동 교정으로 쓰지 않는다. 멤버 생성·의존성·평가 estimand가 점수 이론의 가정을 충족할 때만 별도 민감도로 검토하며, 교환가능성만으로 iid 보정이 정당화되지 않는다. Source 11 [Project P3]
